# Dollmaker — Independent Film Website

A full-stack website developed for an independent film as a paid freelance project.

## Overview

Built to provide information about the film, its cast and crew, and related content, with a contact and mailing-list feature.

## Technologies

- Node.js and Express
- Express Handlebars
- JavaScript, jQuery, HTML, and CSS
- Materialize CSS
- Firebase Realtime Database

## Features

- Dedicated pages for cast, crew, synopsis, merchandise, gallery, and support
- Responsive layouts and image galleries
- Contact and mailing-list functionality
- Server-side routing and templates
- Custom 404 handling

## My Role

I designed, developed, and deployed the website for the client, including frontend development, backend routing, database integration, and deployment.

## Project Status

Completed freelance project from 2018. The original Heroku deployment is no longer maintained. The repository is preserved as an example of my full-stack development work.
